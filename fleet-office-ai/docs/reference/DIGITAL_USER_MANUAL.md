# Digital User Manual & Live Application Map

The signed-in workspace now includes a persistent **You are here** navigator and a dedicated **Digital User Manual**.

## What the user sees

- Current workspace step and page title.
- Role-aware label (Owner, Manager, Employee, Contractor, etc.).
- Suggested next action for the current area.
- **Open map & manual** button.
- A visual 10-step application map with the user's current/origin position highlighted.
- Contextual explanation of the current area.
- Direct buttons to navigate to the relevant workspace section.
- A hand-off to the GDS AI Co-pilot for natural-language guidance.
- Immediate Help Desk access.

## Map

1. Command centre
2. Business setup
3. People & workforce
4. Jobs & allocation
5. AI Operations
6. Content studio
7. Connections
8. Trust & governance
9. Digital user manual
10. Plans & billing

## Role-aware behaviour

The manual changes explanatory text according to the signed-in membership role. Senior roles receive governance/security-oriented guidance. Employees, workers and contractors receive task/policy/help guidance without exposing privileged audit administration.

The manual is a usability layer. It does not grant permissions. Real access remains enforced by backend role and tenant controls.

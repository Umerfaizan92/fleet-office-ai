# Phase 06 prompt (verbatim from the owner, 30 Oct 2026)

SUPER PRO AI — PHASE 06
AUTONOMOUS SEO, GOOGLE AND WEBSITE INTELLIGENCE PLATFORM
Act as a Technical SEO Director, Search Engineer, Content Strategist, Web Architect and AI Automation Specialist.
MISSION:
Build a comprehensive, AI-assisted website and SEO management platform inside Super Pro AI.
Support the Super Pro AI public website and subscriber websites, with strict separation between accounts and permissions.
MODULE A — TECHNICAL SEO
Implement automated auditing for:
• Crawlability
• Indexability
• robots.txt
• XML sitemaps
• Canonical URLs
• Redirects
• Broken links
• HTTP status codes
• Duplicate content
• Structured data
• Meta titles
• Meta descriptions
• Heading hierarchy
• Internal linking
• Image optimisation
• Core Web Vitals
• Mobile usability
• HTTPS
• Internationalisation where applicable
MODULE B — KEYWORD RESEARCH AND CLUSTERS
Build a topic-cluster engine that:
1. Discovers relevant keywords
2. Groups them by search intent
3. Identifies primary and secondary keywords
4. Creates pillar-page recommendations
5. Creates supporting content clusters
6. Detects keyword cannibalisation
7. Suggests internal links
8. Maps clusters to existing pages
9. Identifies content gaps
10. Prioritises opportunities by evidence and business value
Avoid fabricated search volume or ranking data.
MODULE C — AUTOMATED CONTENT
Create AI-assisted:
• Landing pages
• Service pages
• Industry pages
• FAQ content
• Blog articles
• Product descriptions
• Meta descriptions
• Schema markup
• Internal-link suggestions
• Image alt text
• Content refreshes
Use verified business facts and human review for claims requiring validation.
MODULE D — GOOGLE INTEGRATION
Integrate supported, authorised Google services:
• Google Search Console
• Google Analytics 4
• Google Business Profile
• Google Ads where authorised
• Google Tag Manager
• PageSpeed Insights
Use official APIs and OAuth permissions.
Respect each API's availability, limitations, quotas and supported actions.
Do not claim Google indexing or ranking can be guaranteed.
MODULE E — LOCAL SEO
Support:
• Business profile accuracy
• Service areas
• Location pages
• Business categories
• Local structured data
• Reviews and response drafts
• Business hours
• Photos
• Local search performance
• Consistent business contact details
Do not create fake reviews or misleading business locations.
MODULE F — AUTOMATED WEBSITE MANAGEMENT
Implement:
• Visual page builder
• Reusable page templates
• AI-assisted design suggestions
• Brand-aware content generation
• Image optimisation
• Accessibility checks
• SEO checks before publishing
• Preview and staging
• Scheduled publishing
• Version history
• Rollback
• Broken-link monitoring
• Content freshness analysis
• Automated website health reports
Low-risk updates may be automated under owner-approved policies.
Require human approval for material public claims, major design changes, sensitive content and production releases.
MODULE G — SEO OPERATIONS
Create daily, weekly and monthly scheduled tasks:
DAILY: Monitor critical crawl errors, outages, indexing signals and broken pages.
WEEKLY: Analyse search performance, content opportunities and technical issues.
MONTHLY: Prepare SEO performance reports, content clusters and improvement recommendations.
MODULE H — PERFORMANCE MEASUREMENT
Track:
• Organic clicks
• Impressions
• CTR
• Average position
• Landing-page conversions
• Qualified leads
• Technical errors
• Core Web Vitals
• Content performance
• Revenue attribution where supported
Clearly separate actual measurements from AI estimates.
DELIVER:
1. SEO Command Centre
2. Keyword Cluster Engine
3. Technical Audit Engine
4. Google Integration Centre
5. AI Content Studio
6. Website Builder
7. Scheduled SEO Jobs
8. Publishing Approvals
9. Analytics Dashboard
10. Automated Reporting
Every external integration must be tested using real authorised API responses.

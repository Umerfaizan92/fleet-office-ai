# Frontend architecture

- Public site: static pages generated by `scripts/site/` (`templates.mjs`). Rebuild with the site script. 19 pages.
  Design tokens in `docs/design/DESIGN_SYSTEM.md`. A 3D hero (`hero-3d.js`, minified) respects reduced motion.
- Subscriber Workspace: `saas/workspace.html` plus `saas/workspace-*.js/css` modules, one per area
  (e.g. `workspace-comms-platform.js`, `workspace-finance-platform.js`). Views are registered by id
  (b04/unified, b07 finance…). 60 views in 9 groups.
- Founder Console: `office/index.html` (`legacy.html` is an identical copy, kept because scripts use index.html)
  plus `office/console-*.js`. 34 sections in 9 groups. Classic scripts share globals from `office/office.js`.
- No bundler and no framework. Browser tests: `scripts/test-*-ui.mjs` (Playwright), `scripts/visual/`, `report:a11y-perf`.
